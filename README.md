# Prairie Dark Mode

A simple chrome extension for dark mode on PrairieLearn and PrairieTest

## Install

1. Clone this repo
1. Open `chrome://extensions`.
2. Turn on Developer Mode, the toggle is in the top right corner of the screen.
3. Click "Load Unpacked" and select this folder.
4. Refresh your PrairieLearn and PrairieTest tabs.

Use the top-bar button to switch between dark and light mode, your choice is saved
